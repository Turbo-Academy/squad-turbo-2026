# Lições de operação

152 lições sobre fazer agente de IA trabalhar de verdade — testar, medir, guardar segredo, orquestrar
sessões, manter servidor e automação de pé. Cada uma tem três partes: **quando acontece**, **o que fazer** e
**como conferir**. A terceira é a que importa: sem o teste que prova, a lição vira intenção.

Os exemplos são genéricos de propósito. Saíram de operação real, com o nome de quem e de onde tirado.
