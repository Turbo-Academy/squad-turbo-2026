Parte A

Entender

Antes de colar qualquer coisa: o que você está instalando, onde fica e o que sai da sua máquina.

A1O que é o Squad Turbo↑ menu

Um time de agentes de marketing dentro do seu Claude, que trabalha nos seus arquivos.

O Squad Turbo é um pacote para o Claude Code (a aba Code do app do Claude). Ele não é um aplicativo novo: ensina o Claude da sua conta a trabalhar como uma equipe de marketing digital. Você conversa com o @estrategista-turbo, ele entende o pedido e passa o trabalho para especialistas (copy, design, tráfego, conteúdo, vendas, CS), que usam receitas prontas, as skills.

Foi feito para o método de Lançamento Pago Semanal (LPSG), e as skills servem para qualquer negócio digital: página de vendas, VSL, criativos, carrossel, cortes verticais, campanhas de Meta Ads, mensageria, dashboards.

Ele faz sozinho

Ler e escrever arquivos na pasta do projeto, pesquisar, montar páginas, copy e criativos, e conferir o próprio trabalho antes de entregar.

Sempre volta pra você

Gastar dinheiro, publicar, mandar mensagem ou e-mail pra fora, conectar uma conta sua e aprovar qualquer peça que vai pro ar.

A3O que você precisa ter↑ menu

A lista de compras e o tempo de cada parte.

  • Uma assinatura do Claude que inclua o Claude Code (Pro ou Max).
  • Um Mac, ou um Windows 10 ou 11 com o Ubuntu por dentro (WSL2). No Windows o squad roda dentro do Ubuntu; o passo a passo está em B1, aba Windows.
  • Uns 2 GB livres para o básico. Os opcionais pesados (até ~5 GB) são escolha sua.

A4O que sai da sua máquina↑ menu

Nada do seu trabalho vai pra Turbo.

O squad é baixado de um repositório público no GitHub. Ele não cria conta, não manda sinal de vida e não lê nada fora das pastas em que você trabalha. O que você produz fica no seu computador e na sua conta do Claude.

Os opcionais de terceiros (stack Picasso, skills de outros autores) vêm direto da fonte de cada autor, com a licença dele. A lista, com autor e licença, está em SKILLS-DE-TERCEIRO.md.

Já tinha uma versão antiga?

Oi! No Windows são 5 passos.

O squad não roda direto no Windows. Ele roda num Ubuntu (um Linux) que o próprio Windows instala por dentro, o WSL. Os passos 1 a 4 preparam esse Ubuntu e abrem o Claude Code dentro dele; a partir do passo 4 é o Claude que faz o resto. O app Claude do Windows não serve pro squad: ele não enxerga o Ubuntu.

Colar na janela do Ubuntu

Clique com o botão direito dentro dela (ou Ctrl + Shift + V) e aperte Enter.

Copiar da janela do Ubuntu

Selecione com o mouse e aperte Ctrl + Shift + C. O Ctrl + C sozinho interrompe o comando que está rodando.

A sua senha é só sua.

Algumas linhas pedem a senha do Ubuntu (as que começam com sudo). Quem digita é você, na janela do Ubuntu. Enquanto você digita, nada aparece: é normal. Ninguém da Turbo nem o Claude vai pedir essa senha.

ProvaSQUAD OK: 49 skills · 13 agentes · squad-core. Se aparecer SQUAD INCOMPLETO, as linhas com ✗ dizem o que falta: peça ao Claude pra rodar o instalador de novo.

O --conferir compara cada arquivo instalado, byte a byte, com o do pacote. ✗ incompleto é arquivo que falta ou ficou vazio: quebra a skill. ~ personalizado é arquivo que você editou: não é erro, e ele nunca escreve nada.

E2Mac Intel e a Homebrew↑ menu

A linha oficial não instala mais do zero em Mac Intel.

Como saber: maçã no canto da tela → Sobre este Mac. Se aparecer Processador com Intel, é Intel; se aparecer Chip (Apple M1, M2…), não é. Ou rode uname -m: x86_64 é Intel.

Já tem a Homebrew (brew --version responde)? Nada a fazer. Não tem? Desde 13/09/2026 a linha oficial para com Homebrew on macOS is only supported on Apple Silicon processors!. Use a versão anterior do instalador, de antes dessa mudança, no Terminal:

Cole no Terminal do Mac
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/f4aa1b1ca5/install.sh)"

ProvaNo fim aparece Installation successful! e o bloco Next steps; cole esse bloco pro Claude.
